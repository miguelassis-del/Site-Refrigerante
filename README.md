# 🥤 Site-Refrigerante

**Autor:** Miguel Assis

## Sobre
Site com animações criado para uma fornecedora fictícia de refrigerantes, com foco em efeitos visuais, interatividade e apresentação de produtos.

## Tecnologias
- HTML5
- CSS3
- JavaScript

## Estrutura
- `index.html` — estrutura da página
- `style.css` — estilização e animações
- `script.js` — interatividade
- Imagens dos produtos (sabores abacate, laranja e morango)
